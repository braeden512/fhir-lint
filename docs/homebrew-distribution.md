# Homebrew Distribution & Packaging Guide

This guide describes how **FHIRLint** is distributed through [Homebrew](https://brew.sh/) for macOS and Linux users.

---

## 1. Installation Methods

### Method A: Tap & Install (Recommended for CLI users)

By tapping the repository once, users can install and use the short command `fhir-lint`:

```bash
# 1. Tap the repository
brew tap braeden512/fhir-lint

# 2. Install FHIRLint
brew install fhir-lint

# 3. Verify installation
fhir-lint --version
fhir-lint validate sample-data/clean/clean-bundle.json
```

Future updates can be pulled automatically with:
```bash
brew upgrade fhir-lint
```

### Method B: Single-Command Direct Install

Users can install directly in one step without explicitly calling `brew tap`:

```bash
brew install braeden512/fhir-lint/fhir-lint
```

## 2. How the Formula Works

The formula is maintained directly in this repository at [`Formula/fhir-lint.rb`](../Formula/fhir-lint.rb).

### Architecture
- **macOS Apple Silicon (ARM64)**: Downloads `fhir-lint-macos-aarch64` from the matching GitHub release tag.
- **macOS Intel (x86_64)**: Downloads `fhir-lint-macos-x86_64` from the matching GitHub release tag.
- **Linux (x86_64)**: Downloads `fhir-lint-linux-x86_64` from the matching GitHub release tag.
- **Integrity**: Each download is verified against the cryptographic SHA-256 digest generated by the release workflow.
- **Installation**: Installs the native binary directly into Homebrew's prefix (`/opt/homebrew/bin/fhir-lint` on Apple Silicon or `/usr/local/bin/fhir-lint` on Intel/Linux).
- **Zero Runtime Dependencies**: Because it installs the GraalVM native binary, users do not need a Java Virtual Machine or JDK installed on their machine.

## 3. Automated Formula Maintenance on Release

When a new version tag (`v*.*.*`) is published, the release workflow in [`.github/workflows/release.yml`](../.github/workflows/release.yml) compiles the binaries and generates their `.sha256` files.

To update the formula on release, the workflow computes the new hashes and updates `Formula/fhir-lint.rb`:

```ruby
version "0.1.0"

on_macos do
  if Hardware::CPU.arm?
    url "https://github.com/braeden512/fhir-lint/releases/download/v#{version}/fhir-lint-macos-aarch64"
    sha256 "<computed-arm64-sha256>"
  else
    url "https://github.com/braeden512/fhir-lint/releases/download/v#{version}/fhir-lint-macos-x86_64"
    sha256 "<computed-x86-sha256>"
  end
end

on_linux do
  if Hardware::CPU.intel?
    url "https://github.com/braeden512/fhir-lint/releases/download/v#{version}/fhir-lint-linux-x86_64"
    sha256 "<computed-linux-sha256>"
  end
end
```

## 4. Path to Homebrew Core (`brew install fhir-lint`)

Once FHIRLint reaches initial public adoption (v0.1.0 or v1.0.0):

1. **Prerequisites for Homebrew Core**:
   - Tagged stable GitHub release with downloadable source and release notes.
   - Initial project traction and active usage.
   - Clean, passing `brew audit --strict --online Formula/fhir-lint.rb`.

2. **Submission Process**:
   - Fork [`Homebrew/homebrew-core`](https://github.com/Homebrew/homebrew-core).
   - Create a branch: `git checkout -b new-formula-fhir-lint`.
   - Add the formula to `Formula/f/fhir-lint.rb`.
   - Test locally: `brew install --build-from-source Formula/f/fhir-lint.rb` and `brew test fhir-lint`.
   - Open a pull request against `Homebrew/homebrew-core`.

3. **After Acceptance**:
   - The formula is maintained by Homebrew and built on their build infrastructure.
   - Any user anywhere can run `brew install fhir-lint` with zero tapping required.
